# ✊✋✌️ Rock Paper Scissors Game

A simple, interactive, and responsive **Rock Paper Scissors** web application built using HTML, CSS, and Vanilla JavaScript. Play against the computer, track live scores, and get real-time game status updates!

---

## 🚀 Features

* **Interactive Gameplay:** Play Rock, Paper, or Scissors against a randomized computer choice.
* **Live Scoreboard:** Real-time score tracking for both Player and Computer.
* **Dynamic Status Messages:** Clear display messages indicating wins, losses, or draws with custom details.
* **Responsive UI:** Clean, modern, and user-friendly interface.

---

## 🛠️ Tech Stack

* **HTML5:** Game structure and elements
* **CSS3:** Styling, colors, and layout
* **JavaScript (ES6):** Game logic and score management
